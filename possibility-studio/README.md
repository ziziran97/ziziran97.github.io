# 把想法变成世界

An interactive 3D portrait of Ziziran, built from the corrected Blender scene.

Explore at https://ziziran97.github.io/possibility-studio/

Drag to orbit, pinch or scroll to zoom. Use the chapter buttons for three close-up views. The viewer includes day/night lighting, optional auto-rotation, reset, and a downloadable GLB model.

The site serves all model, decoder, script, and font assets locally. No analytics or external runtime CDN is used.
